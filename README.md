# 🎨 DevArt .NET –--- UI Design & Application Showcase

DevArt is a modern handicraft shopping application focused on providing a premium and minimalist shopping experience. This repository currently contains the complete high-fidelity UI/UX design created in **Figma**, with development planned using the **.NET ecosystem**.

The project emphasizes clean layouts, earthy color palettes, smooth user flows, and a modern shopping experience for handcrafted products.

---

## ✨ Current Design Progress

The following application screens have been designed in Figma:

- 🏠 Home Page
- 📂 Categories Page
- 🛍️ Handicraft Items Listing
- 📦 Product Details Page
- ❤️ Wishlist Page
- 🛒 Shopping Cart
- 💳 Checkout Page
- ✅ Order Success Screen

More screens and user flows will be added as the project progresses.

# 🎨 Design Highlights

DevArt follows a clean, organic, and premium visual language.

### 🌿 Organic Minimalism
- Earth-inspired color palette
- Soft shadows
- Rounded corners
- Spacious layouts

### 🛍️ Modern Shopping Experience
- Easy product browsing
- Wishlist management
- Smooth checkout flow
- Clean product presentation

### 🎯 User Experience
- Intuitive navigation
- Consistent spacing
- Simple interactions
- Accessible interface
